# 模型ICIR测试文档

## 一、测试目的

评估优化后模型的预测能力，验证特征因子分类和训练参数调整的效果。

## 二、测试指标说明

### 2.1 IC（Information Coefficient）

**定义**：预测值与真实标签之间的相关性

- **Pearson IC**：线性相关性
- **Spearman IC（Rank IC）**：排序相关性，对异常值更稳健

**计算公式**：
```
IC = corr(预测值, 真实标签)
```

**评估标准**：
| IC均值 | 评级 |
|--------|------|
| > 0.05 | 优秀 |
| 0.03 ~ 0.05 | 良好 |
| 0.01 ~ 0.03 | 一般 |
| < 0.01 | 较差 |

### 2.2 ICIR（Information Coefficient Information Ratio）

**定义**：IC的夏普比率，衡量预测稳定性

**计算公式**：
```
ICIR = IC均值 / IC标准差
```

**评估标准**：
| ICIR | 评级 |
|------|------|
| > 0.5 | 优秀 |
| 0.3 ~ 0.5 | 良好 |
| 0.1 ~ 0.3 | 一般 |
| < 0.1 | 较差 |

### 2.3 IC正向比例

**定义**：IC为正的窗口占比

**评估标准**：
- > 60%：模型预测方向稳定
- 50% ~ 60%：预测方向基本正确
- < 50%：预测方向不稳定

## 三、测试方法

### 3.1 滚动窗口测试

```
测试窗口数量：3个
每个窗口包含：
- 训练期：按模型配置（LGBM: 480天, GRU: 180天）
- 验证期：20天
- 测试期：20天
滚动步长：10天
```

### 3.2 测试流程

```
1. 加载配置文件
2. 生成滚动窗口
3. 对每个窗口：
   a. 训练模型（使用各自的训练窗口和特征集）
   b. 在测试集上预测
   c. 计算IC和Rank IC
4. 汇总统计：
   a. 计算各模型IC均值、标准差、ICIR
   b. 计算IC正向比例
   c. 输出对比表格
```

## 六、结果解读

### 6.1 ICIR > 0.3

模型具有良好的预测能力和稳定性，可以进入实盘测试。

### 6.2 ICIR 0.1 ~ 0.3

模型预测能力一般，需要进一步优化：
- 检查特征工程质量
- 调整模型超参数
- 增加训练数据

### 6.3 ICIR < 0.1

模型预测能力较差，需要：
- 重新设计特征因子
- 检查数据质量
- 考虑更换模型架构

## 八、注意事项

1. **数据质量**：确保数据无缺失、无异常值
2. **过拟合风险**：ICIR过高可能存在过拟合，需关注样本外表现
3. **市场环境**：不同市场环境下IC可能波动较大
4. **模型稳定性**：关注IC的时间序列稳定性，避免大幅波动

## 九、后续优化方向

1. 如果ICIR不达标：
   - 增加特征因子
   - 调整训练窗口
   - 尝试不同的模型组合

2. 如果ICIR达标：
   - 进入回测验证
   - 评估交易成本影响
   - 准备实盘部署
